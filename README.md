# chapter-learning-workflow · 章节学习沉淀工作流 Skill

> 把「一个学习章节」从原始课堂录音，自动沉淀为 **汇总文档 + 复习播客 + 思维导图 + 章节作业 + 群发布** 的完整可复用流水线。

**作者**：蒋恩晶（Enjing Jiang）· 清华大学深圳国际研究生院 · AI Agent 应用开发学习笔记工作流

---

## 🎯 这是什么

我在系统学习 AI Agent 开发（丁师兄大模型训练营·阶段八「Agent 开发精讲与实战」，63 讲 / 6 大里程碑，以及 GraphRAG、上下文工程、MCP/A2A/ANP 协议、DeepResearch、Function Calling 微调等章节）的过程中，反复执行同一套「学习沉淀」动作：

1. **每节课录音**，课后自动生成飞书智能纪要；
2. **一个章节学完**，把 N 份纪要**去重合并**（删除口播话术、重复讲解）成一份结构化汇总文档；
3. 基于汇总内容生成 **30–40 分钟中文复习播客**（通勤/睡前复习用）；
4. 画一张 **markmap 交互式 HTML 思维导图**，把整个章节的知识脉络串起来；
5. 按课程要求完成章节 **「三大学习任务」** 总结：结构化内容讲解、面试题脱稿稿、代码逐段中文注释 + 完整复现；
6. 全部资料发布到飞书 **「AI打卡群」**，并按需把文档权限开放为「所有人可阅读」。

这套流程被完整封装为**一个 AI Agent Skill（技能包）**：以后学「阶段九」「阶段一」「阶段二」……任何新章节，只要触发该 Skill，就能按同一套标准自动跑完整个闭环——**录音 → 纪要 → 汇总 → 播客 → 导图 → 作业 → 发布**，沉淀可复习、可面试、可分享的学习资产。

## 🏗️ 工作流总览（S0 → S5）

| 阶段 | 做什么 | 产出 |
|---|---|---|
| **S0 素材收集** | 启动录音、收集本阶段全部智能纪要（飞书文档） | 智能纪要 docx |
| **S1 汇总去重** | 逐一读取纪要全文，去重合并，按「里程碑 → 讲次/主题 → 要点」重组 | 章节汇总飞书文档 |
| **S2 复习播客** | 口语化问答式脚本，分段 TTS 生成，ffmpeg 拼接 + 压缩到 20MB 内 | 30–40 分钟中文播客 mp3 |
| **S3 思维导图** | markmap-autoloader 模板填充章节结构，桌面/移动双视口截图验证**无文字重叠** | 交互式 HTML 思维导图 + 截图 |
| **S4 章节作业** | 三大任务：结构化内容讲解 / 全部面试题脱稿稿 / 代码逐段注释+完整复现（可附学习总结模板） | 《第X阶段学习总结》飞书文档 |
| **S5 发布** | 发到指定飞书群（默认「AI打卡群」），按需开放文档权限 | 群消息 + 权限配置 |

## ✅ 质量红线（踩坑沉淀）

- **内容去重**：同一知识点多场课重复讲，只保留最完整表述，删除寒暄话术；
- **导图无重叠**：思维导图必须用截图脚本双视口验证（曾因文字重叠返工，改用 markmap 后根治）；
- **面试题口语化**：脱稿稿按「结论先行 → 分层展开 → 带例子 → 收尾」写，能直接背诵；
- **代码真实**：代码注释基于真实源码逐段编写，禁止编造（曾踩坑：`transpose(-2,-1)` 维度报错、API Key 401、serpapi 缺失）；
- **文件上限**：播客 >20MB 会被飞书拒收，统一压缩到 ~18MB；
- **数字可溯源**：联网补充内容必须附来源。

## 🚀 如何使用

1. 把 `chapter-learning-workflow/` 整个文件夹放入 AI Agent 的 Skills 目录（如 `workspace/.user_skills/`）；
2. 新章节开始时对助手说一句「用章节学习工作流」；
3. 每节课照常录音，章节学完时对助手说「汇总这几场录音并生成播客和思维导图」「完成本章节三大任务作业」「发到 AI 打卡群」。
