## 1. 文档总结构

标题：《第X阶段……学习总结》（如《第八阶段Agent开发学习总结》）
建议 5 大部分：

1. 学习总览：学习路径表（天数/里程碑/难度）、重点方向表、学完效果
2. 任务一 · 核心内容讲解
3. 任务二 · 面试题脱稿稿
4. 任务三 · 代码实战全注释
5. 参考资料（代码路径、文档 token、来源说明）

## 2. 任务一：结构化内容讲解

- 按课程「学习框架」的 5 大主题组织（不同阶段主题不同，通用主题示例）：
  - Agent 三大范式（ReAct / Plan-and-Solve / Reflection）
  - 框架核心能力（如 LangGraph：状态图/中间件/记忆/多Agent 编排）
  - RAG / GraphRAG 架构（全链路、索引/查询、局限与改进）
  - 上下文工程（Context Engineering）
  - 协议体系（MCP / A2A / ANP / Agent Skills）与 DeepResearch 实现
- 素材优先级：PDF 讲稿 > 历史录音纪要（飞书文档）> 用户提供的知识框架 > 联网检索
- 每个主题必须：结论先行 → 分层展开 → 配 1 张架构/流程图解（HTML block 或 SVG）→ 面试考点标注
- 联网补充的内容必须附来源（URL），不编造
- 图解配色遵循用户偏好：学术材料用「清华紫」#CC00CC、白底、大字体少文字

## 3. 任务二：面试题脱稿稿

- 收集来源：课程面试题讲次 + 历史汇总文档面试题 + 录音中老师提问 + 联网高频题（去重合并）
- 每题格式：问题 → 脱稿稿（口语化第一人称，300-500 字，可背）
- 回答结构固定：「结论先行 → 分层展开（2-4 点）→ 带例子/类比 → 收尾总结」
- 按主题分组（如 Agent 基础 / 框架选型 / RAG 评估 / GraphRAG / 多模态 / 协议 / DeepResearch / 微调）
- 标注优先级：⭐⭐⭐ 高频必背、⭐⭐ 理解即可

## 4. 任务三：代码实战注释 + 完整复现

- 代码根目录由用户提供（如 `阶段8/代码/8.agent-stage/`），必须**真实读取**每个 ipynb 源码，禁止编造
- 重点代码清单（以阶段八为例）：Agent-ReAct、Plan-and-Solve、Agent-Reflection、Agent RAG（LangGraph）、多模态 RAG 三方案、GraphRAG 工程化、上下文工程、MCP 服务、DeepResearch 实现、Agent+Function Calling 训练微调
- 每段代码输出：完整代码（可运行） + 逐段中文注释（# 说明） + 易错点（如 transpose(-2,-1)、API Key 配置）+ 运行输出示例
- 补读支撑文件：llm_client.py / tools.py 等，还原完整可运行版本
- 复现要求：① 跟视频跑通 → ② 关视频自己写 → ③ 从零手撕

## 5. 学习总结模板（用户作业模板）

用户在章节结束后常按此模板交作业，需「结合用户问过的问题」填写：

- 🧠 阶段脑图：思维导图截图（S3 产物）
- 💻 手撕代码：三遍法 + 关键代码片段（贴用户自己写过的/踩坑修正过的）
- 💎 学习总结：
  - ✅ 做的好的（1-3 条）
  - ⚠️ 待改进的（1-3 条）
  - 📒 遇到的问题（结合用户真实问过的技术问题；难题标【难】）
  - 🔍 解决方案（用自己的话写清楚：问题 → 我的理解）
  - 🚀 下阶段计划（5 条）

## 6. 创建流程与质量要求

- 用 `lark-doc` create-workflow：`init-draft`（Presentation Decision）→ 写 XML → `parse` 校验（passed 才能建）→ `create` → `fetch` 回查验证
- 图片插入用 `<img path="@绝对路径"/>`；代码块用 `<pre lang="python"><code>…</code></pre>`（& < > 需转义）
- 创建后必须 fetch 回查（内容完整、图片已上传）
- 文档创建后默认交付 `present_files`；如用户要求发群，走 S5
