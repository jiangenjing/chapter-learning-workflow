# 复习播客规范（podcast-spec）

## 目标

- 时长：30-40 分钟（复习用途，覆盖一个章节全部核心内容）
- 风格：中文男声、口语化、问答式、有节奏（开场→逐节→问答→总结）
- 用途：用户通勤/睡前复习，可反复听

## 脚本结构

1. 开场（1 分钟）：本章节主题 + 收听地图（今天讲哪几个大块）
2. 逐里程碑回顾（每块 4-6 分钟）：
   - 核心概念用「一句话定义 + 例子」
   - 每个里程碑讲完给「一句话小结」
3. 高频面试题问答（5-8 分钟）：模拟面试官提问 + 脱稿回答示范
4. 结尾（1 分钟）：易错点提醒 + 下阶段预告

## 生成方式（seed-audio）

- 工具：`text_to_audio_plus`（无参考音频时）
- 单次 duration ≤ 120 秒 → 长播客必须**分段生成**（每段一个脚本小节，约 90-110 秒/段）
- 每段 Prompt 写法：`30 岁沉稳男声，中文自然口播讲解：……（该段完整讲稿文字）`
- 先取每段脚本 → 并行/串行生成各段音频 URL → **立即下载**（aka.doubaocdn.com 短链会过期）

## 拼接与压缩（ffmpeg）

- 多段 wav/mp3 拼接：`ffmpeg -f concat -safe 0 -i list.txt -c copy out.mp3`
- 超 20MB（飞书消息文件上限）时压缩：
  `ffmpeg -i in.mp3 -ac 1 -b:a 64k -y out_压缩版.mp3`（35MB → 约 18MB）
- 也可用本 skill 的 `scripts/compress_mp3.sh`
- 命名：`{章节}复习播客_{MMDD}.mp3`，压缩版加 `_压缩版`

## 交付

- 播客发群用 `lark-cli im +messages-send --chat-id <群> --file ./xxx.mp3`（cwd 相对路径）
- 交付给用户用 `present_files`
